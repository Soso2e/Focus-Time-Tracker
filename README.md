# 集中時間トラッカー

クリエイターの「集中の質」を可視化し、努力がちゃんと報われる時間トラッカー

## 特徴

- **自動監視**: アクティブウィンドウを自動で記録
- **スマートAFK**: レンダリング中などは作業継続と判定
- **Glue機能**: 調べ物で集中が途切れない
- **集中セッション**: 連続作業を自動認定
- **プライバシー重視**: ローカルファーストでデータは端末外に出さない

## セットアップ

### 必要要件

- Python 3.10以上
- Windows 10/11 または macOS 10.15以上

### インストール

```bash
# 依存パッケージのインストール
pip install -r requirements.txt

# アプリケーションの起動
python src/main.py
```

### macOSでの注意事項

macOSでは、アクティブウィンドウ情報の取得にアクセシビリティ権限が必要です。
初回起動時に権限付与を促すダイアログが表示されます。

## 使い方

1. アプリケーションを起動すると、システムトレイに常駐します
2. バックグラウンドで自動的にアクティブウィンドウを記録
3. トレイアイコンをクリックしてダッシュボードを表示
4. カテゴリ設定で自動分類ルールをカスタマイズ可能
