# 集中時間トラッカー (Focus Time Tracker)

クリエイターの「集中の質」を可視化し、努力が報われる様子を記録する時間追跡アプリケーション。

## 🎯 概要
このアプリケーションは、ユーザーのPC操作をバックグラウンドで監視し、アクティブなアプリケーションを記録します。単なる時間記録だけでなく、「集中セッション」を自動的に検出し、クリエイターが「フロー状態」に入っていた時間を可視化することを目的としています。

## 🏗 アーキテクチャ設計

### コアコンポーネント構成
- **EventCollector**: アクティブウィンドウの変更を検知し、生イベントデータとして収集。
- **AFKDetector**: マウス・キーボード操作を監視し、離席（AFK）状態を判定。
- **SessionDetector**: 蓄積されたイベントから「集中セッション」を検出・生成。
- **GlueEngine**: 「調べ物」などの短い中断を許容し、作業の文脈を繋ぐロジックエンジン。
- **Database**: SQLiteを使用したローカルデータストア。

### テクノロジースタック
- **言語**: Python 3.10+
- **GUI**: PySide6 (Qt for Python)
- **監視**: `pywin32` (Windows API), `psutil`
- **DB**: SQLite3

## ⚙️ 詳細仕様

### 1. イベント収集 (Event Collection)
- **ポーリング/イベント駆動**: Windows APIフックによりアクティブウィンドウの変更を即座に検知。
- **データ構造**:
  - `app_name`: アプリケーション名 (例: `maya.exe`, `chrome.exe`)
  - `window_title`: ウィンドウタイトル (ブラウザのタブ名など)
  - `timestamp`: 開始・終了時刻
- **特徴**:
  - **リアルタイム更新**: 現在進行中のイベントの終了時刻は30秒ごとにDB上で更新され、UIに即座に反映されます。

### 2. AFK (Away From Keyboard) 検知
- **ロジック**: マウス移動距離とキーボード入力イベントを監視。
- **閾値**: デフォルト60秒（設定で変更可能）。
- **ステータス**:
  - **Active**: 操作あり。
  - **Idle**: 操作なしだが閾値未満。
  - **AFK**: 閾値を超えて操作なし。
- **通知**: AFK開始時、作業復帰時にバルーン通知を送信。

### 3. セッション検出 & Glue機能 (The "Core" Logic)
ここが本アプリの核となるロジックです。

#### セッション認定条件
- 同一のメインアプリ（または関連アプリ）での作業が **10分以上** 継続した場合、「集中セッション」として認定。

#### Glue（接着）機能
クリエイターの作業は直線的ではありません。「Mayaで作業中」に「Chromeで資料検索」を1分だけ行い、また「Maya」に戻ることは頻繁にあります。
- **ロジック**: 
  - メインアプリ以外のアプリ使用時間が **60秒未満** で、かつカテゴリが「調べ物」「連絡」の場合、セッションの中断とはみなさず、1つの連続したセッションとして結合（Glue）します。

#### 重複排除と更新ロジック
- **ユニーク制御**: `(開始時刻, アプリ名)` をキーとしてセッションを管理。
- **更新フロー**: 
  1. 10分経過時に最初のセッションレコードを作成。
  2. その後10分ごとにチェックが走り、既存のレコードがあれば `end_at` と `duration` を更新（新規レコードは作成しない）。
  3. これにより、長時間の作業もデータベース上では「1つの長いセッション」としてきれいに保存されます。

### 4. 通知システム
- **達成通知**: 集中セッション時間が **10分の節目**（10分, 20分, 30分...）を超えたタイミングでのみ通知を送信。
- **過剰通知の防止**: 短時間の更新で何度も通知が来ないよう制御されています。
- **Windows標準通知**: ネイティブのトースト/バルーン通知を使用し、作業を邪魔しません。

### 5. カテゴリ分類
- **ルールベース**: `app_name` や `window_title` のキーワードマッチングにより自動分類。
- **優先度**: タイトルマッチ > アプリ名マッチ > プロセス名マッチ。
- **カラーコーディング**: カテゴリごとに色を設定し、UI上で直感的に識別可能。

## 🗄 データベース設計 (SQLite)

### `events` テーブル
生の操作ログを記録。
| Column | Type | Description |
|---|---|---|
| id | INTEGER PK | |
| start_at | TIMESTAMP | 開始時刻 |
| end_at | TIMESTAMP | 終了時刻 |
| app_name | TEXT | アプリ名 |
| window_title | TEXT | ウィンドウタイトル |
| category_id | INTEGER | |
| is_afk | BOOLEAN | AFKフラグ |

### `sessions` テーブル
認定された集中セッション。
| Column | Type | Description |
|---|---|---|
| id | INTEGER PK | |
| start_at | TIMESTAMP | 開始時刻 |
| end_at | TIMESTAMP | 終了時刻 |
| main_app_name | TEXT | メインで使用したアプリ |
| duration_minutes | INTEGER | 継続時間(分) |
| category_id | INTEGER | |

## 🚀 セットアップと実行

### 必要要件
- Windows 10/11 (推奨)
- Python 3.10+

### インストール
```bash
pip install -r requirements.txt
```

### 実行
```bash
python src/main.py
```
または `launch.bat` をダブルクリック。
